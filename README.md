# 🔐 Login & Registration Form

A modern and responsive **Login & Registration Form** built using **HTML, CSS, and JavaScript**.
This project demonstrates a simple and clean user authentication interface with basic client-side validation.

---

## 📌 Features

* 🔄 Toggle between Login and Registration forms
* 🎨 Clean and responsive UI design
* ✅ Basic form validation using JavaScript
* ⚡ Lightweight and fast (no external libraries)

---

## 🚀 Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
