## 📄 Description
A sleek and responsive authentication UI project showcasing front-end development skills using HTML, CSS, and JavaScript. This project is designed to provide a visually appealing and user-friendly interface for users to register and log in.

## 🎯 Features
* Responsive design for seamless user experience across various devices
* Clean and minimalistic UI for easy navigation
* Validation for registration and login forms
* Interactive elements for enhanced user engagement

## 🚀 Tech Stack
* CSS: used for styling and layout
* HTML: used for structuring content
* JavaScript: used for adding interactivity

## 🗂️ Project Structure
The project consists of a single folder, `code/`, containing all the necessary files for the project.

## 📦 Installation
1. Clone the repository: `git clone https://github.com/ubadasiyal88/Login---Registration---Form.git`
2. Open the `code/` folder in a code editor
3. Open the `index.html` file in a web browser to view the project

## 📊 Usage
To use this project, simply open the `index.html` file in a web browser. The project is fully functional and can be used as a starting point for further development.
